# frequencies-reports

This repo exists to maintain clean artist biographies. If you've ever wondered what happens which you click the thumbs down on an artist biography, this is where those go.

If you'd like to submit a bug report for the application, head on over to [the main repo](https://github.com/iFeelLikeChicken2Nite/Frequencies/issues) and create a new issue there - or just create one here.
